# Deek PM Desktop

Deek PM 是个人资料库桌面客户端，支持三种运行方式：

1. 纯离线本地模式：Electron + SQLCipher，数据和托管文件只保存在本机。
2. 官方云服务：连接构建时配置的 Deek PM 官方 API。
3. 自部署服务：连接用户自己部署的同一套 Deek PM API。

项目不提供成员协作和邀请功能。服务端账号只对应自己的个人资料库。

服务连接和当前运行模式相互独立：切回本地库不会删除已保存连接。连接元数据保存在本地 SQLCipher 数据库，可复用的访问令牌还会经过系统 `safeStorage` 加密；令牌过期后只需重新输入密码。

## 本地开发

```bash
npm install
npm run dev
```

如需连接本机服务端，在首页选择“自部署服务”，地址填写 `http://127.0.0.1:3100`。

构建官方客户端前复制 `.env.example` 为 `.env.production` 并设置 `VITE_OFFICIAL_SERVICE_URL`。该变量只包含 API 根地址，不包含数据库凭据。

## 文件与迁移

- 离线模式的正文图片和托管附件默认保存在 Electron `managed-assets` 目录，也可在设置页迁移到其他磁盘的 `deek-pm-assets` 专用目录；路径配置保存在本地 SQLCipher 数据库。
- 加密备份包含数据库内容和适合内嵌的托管文件；单个超过 16 MB 的大文件需要同时备份物理存储目录，避免生成超大内存备份包。
- “备份与迁移 → 迁移到线上”可把本地资料复制到官方或自部署服务，不删除本地数据。
- 本机文件/目录路径引用不会上传，因为服务器和其他设备无法访问这些路径。

服务端部署与存储配置说明见 [`../server/README.md`](../server/README.md)。
