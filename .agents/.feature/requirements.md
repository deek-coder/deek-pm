# Deek PM 需求文档

## 当前原型范围

当前原型用于验证主流程和信息架构，不要求真实持久化和完整业务实现。

已覆盖：

- 启动后选择工作空间实例。
- 本地个人库固定一个，免登录进入。
- 服务端空间可多个实例。
- 官方云服务和自部署服务统一为服务端空间。
- 服务端空间进入前需要登录。
- 进入空间后显示项目列表。
- 进入项目后显示智库。
- 智库支持文本型、密码型、链接型条目。
- 本地空间有备份与恢复。
- 服务端空间有成员与邀请。
- 空间设置按本地/服务端展示不同配置。
- 顶部保留多标签窗口模式。

## 工作空间

### 本地个人库

- 固定一个。
- 免登录。
- 数据存储在本机。
- 支持项目、智库、备份与恢复、空间设置。
- 不支持成员邀请、团队权限、审计。

### 服务端空间

- 可以有多个实例。
- 需要登录。
- 可来自官方云服务或自部署服务。
- 支持项目、智库、成员邀请、角色权限、审计、空间设置。
- 官方云和自部署使用同一套接口模型。

## 项目

项目属于某个工作空间。

项目包含：

- 项目名称。
- 项目描述。
- 项目标签。
- 创建时间。
- 更新时间。
- 智库条目。

## 智库

智库是项目内的信息管理功能。

条目类型：

- 文本型：富文本内容，可记录本地路径或网页链接。
- 密码型：支持多条名称 + 内容，内容可显示/隐藏。
- 链接型：支持多个本地文件、文件夹或网页链接。

公共属性：

- 名称。
- 类型。
- 备注。
- 标签。
- 创建时间。
- 更新时间。

## 本地备份与恢复

本地个人库需要显眼的安全入口。

能力：

- 加密备份。
- 恢复备份。
- 自动备份。
- 迁移到服务端空间。

建议备份格式：

```txt
SQLite 快照 + 附件索引 + 元数据清单
  -> 压缩
  -> AES-GCM 加密
  -> .deekbak
```

## 服务端成员与权限

服务端空间支持：

- 成员邀请。
- 角色管理。
- 项目访问权限。
- 审计记录。

建议角色：

- 所有者。
- 管理员。
- 编辑者。
- 只读。

## 后续可补但不影响主逻辑

- 新建项目弹窗。
- 新建/编辑条目的完整弹窗。
- 成员邀请弹窗。
- 自部署服务测试连接状态。
- 本地备份密码输入弹窗。
- 密码条目的复制、查看记录。
- 权限角色更细的交互。
- 附件/本地文件选择器交互。
- 空状态和错误状态。
