# TASK-0002 本地统一资产与双存储驱动

## 目标

让本地正文图片和附件统一引用 Asset，并支持本机目录与 S3 兼容存储。

## 所属核心流程

上传资产、插入正文、添加附件、读取和释放资产。

## 本次范围

- 本地资产元数据、引用和清理任务表。
- 文件系统/S3 存储端口与配置。
- 旧 managed-assets URL 数据迁移。
- 设置页存储驱动选择与连通性测试。

## 不在本次范围

- 服务端 worker 和服务端 schema 调整。

## 操作角色

- 本地个人库用户。

## 前置状态

- TASK-0001 完成。

## 成功结果

- 两类业务内容统一引用 Asset；切换驱动经过复制、校验和提交。

## 失败结果

- S3 不可用、迁移校验失败时保留原驱动和原文件。

## 数据表

- `assets`、`asset_references`、`asset_cleanup_jobs`、`local_settings`。

## API / 页面

- 扩展本地 Asset Repository 和存储设置页。

## 事务要求

- 元数据与引用同事务；物理清理异步重试。

## 审计日志

- 记录本地迁移结果和错误摘要，不记录凭据。

## 测试用例

- 文件系统与 S3 适配器契约测试。
- 旧数据迁移和失败回滚。
- 正文、附件共享资产的引用计数。

## 完成后更新

- 数据模型、设置文档、备份 manifest。
