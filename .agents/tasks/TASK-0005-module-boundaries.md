# TASK-0005 关键模块拆分与能力接口

## 目标

把资产、存储设置和后台清理从巨型入口文件中拆出，并让 Repository 明确声明可用能力。

## 所属核心流程

资产上传/读取/删除、存储设置、页面加载和备份能力判断。

- 服务端资产路由与资产领域服务模块化。

- 前端重型页面按路由懒加载；Repository 的备份能力不再通过运行时抛错表达。
