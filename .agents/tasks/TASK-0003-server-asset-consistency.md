# TASK-0003 服务端资产最终一致性

## 目标

让服务端文件系统和 S3 使用相同资产状态机，并消除数据库已提交但接口报失败的问题。

## 所属核心流程

服务端资产上传、引用、释放和清理。

## 本次范围

- 完善资产状态与去重约束。
- 新增资产引用和清理任务。
- 删除项目/分组/条目时事务化释放引用和创建任务。
- 增加可重试清理 worker 与 API 集成测试。

## 不在本次范围

- CDN、转码和病毒扫描。

## 操作角色

- 服务端空间编辑者、实例管理员、后台 worker。

## 前置状态

- 统一资产契约已稳定。

## 成功结果

- 业务删除成功不依赖物理存储在线；失败任务可重试；并发上传安全去重。

## 失败结果

- 无权限、跨空间引用、上传未完成均不会发布 ready 资产。

## 数据表

- `assets`、`asset_references`、`asset_cleanup_jobs`。

## API / 页面

- 维持现有资产 HTTP 主契约，细化错误码。

## 事务要求

- 业务删除、释放引用、创建清理任务同一 PostgreSQL 事务。

## 审计日志

- 记录清理任务次数和最后错误，不记录 S3 凭据。

## 测试用例

- 文件系统/S3 故障、重复上传、并发删除、任务重试、跨空间访问。

## 完成后更新

- 服务端 README、API 契约和运维说明。
