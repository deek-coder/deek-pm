# TASK-0001 安全备份恢复

## 目标

恢复本地备份时保留未内嵌的大文件，并保证目录切换失败可以恢复原目录。

## 所属核心流程

本地库备份与恢复。

## 本次范围

- 将资产恢复从“全目录替换”改为“以现有目录为基线的合并恢复”。
- 对备份内资产做路径和内容校验。
- 补充保留大文件、覆盖同路径文件和失败回滚测试。

## 不在本次范围

- S3 备份恢复。
- 新资产数据表。

## 操作角色

- 本地个人库用户。

## 前置状态

- 用户已解锁本地库并选择有效备份。

## 成功结果

- 备份内文件被恢复；当前目录中备份未包含的文件不被静默删除。

## 失败结果

- 非法路径、非法 Base64 或文件系统错误时返回错误，并保留恢复前目录。

## 数据表

- 本任务不修改 schema。

## API / 页面

- 保持现有 `restoreLocalAssets` IPC 契约。

## 事务要求

- 使用 staging/previous 目录交换，失败时恢复原目录。

## 审计日志

- 本地模式暂不增加审计。

## 测试用例

- 未内嵌的大文件继续存在。
- 备份中同路径文件覆盖旧内容。
- 非法路径和非法内容不会破坏原目录。

## 完成后更新

- 更新 `current-stage.md` 和本地 README 的恢复语义。
