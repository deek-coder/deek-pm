# 垂直切片拆分

## 拆分原则

- 每个切片都包含必要的数据、业务逻辑、适配器和测试。
- 先消除数据丢失风险，再统一模型，最后拆分模块和优化性能。

| 顺序 | 切片 | 状态 | 验收标准摘要 |
| --- | --- | --- | --- |
| 1 | 安全备份恢复 | done | 恢复不会删除未内嵌大文件，故障可回滚且有测试 |
| 2 | 本地统一资产与双存储驱动 | done | 正文图片/附件统一资产，本地目录和 S3 可切换 |
| 3 | 服务端资产最终一致性 | done | 文件系统/S3 共用状态机，清理可重试，无假失败 |
| 4 | 层级与跨项目约束 | done | 本地和服务端拒绝跨项目、自引用和循环 |
| 5 | 模块拆分与能力接口 | done | 页面、路由、Repository 按职责拆分 |
| 6 | 集成测试与体积治理 | done | 高风险链路有测试，编辑器和语言包按需加载 |
