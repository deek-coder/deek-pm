# ADR-0001 服务端继续使用 Node.js

## 状态

accepted

## 背景

当前服务端承担 HTTP API、PostgreSQL、密码学封装以及文件系统/S3 流式传输。已发现的问题集中在事务边界、约束和模块职责，而非运行时吞吐瓶颈。

## 决策

继续使用 Node.js 22.12+、TypeScript 和 Fastify，优先完成领域服务、存储端口、最终一致性和测试建设。客户端与服务端共享纯 TypeScript 契约，但不共享基础设施实现。

## 后果

- 保留现有实现和团队认知，重构成本更低。
- Electron 主进程、客户端和服务端可共享类型与验证规则。
- CPU 密集任务不得阻塞 API 事件循环；未来转码/扫描可拆为 Go/Rust worker。
- 若出现经过压测确认的运行时瓶颈，再以指标驱动局部迁移。
